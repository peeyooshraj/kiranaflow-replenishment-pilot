# Real-shop pilot questions

## Ask the shopkeeper before installation

1. How do you know what stock you have now?
2. Where is every sale recorded?
3. When new goods arrive, who records them?
4. How do you decide what to order?
5. Give one item that often runs out. Why does it happen?
6. Give one item that often sits for too long.
7. If a customer asks for an unavailable item, do you record that request?
8. How many products do you roughly carry?
9. Can your present system export Excel or CSV?
10. How do you send orders to suppliers today?
11. How long do suppliers normally take to deliver?
12. What would make this pilot annoying enough that you would stop using it?

## Ask after every trial day

1. Did system stock match the shelf for the items checked today?
2. Which recommendation did you change?
3. Why did you change it?
4. Did anything run out today?
5. Did a customer ask for something that was unavailable?
6. What did you still need to write on paper?
7. Which screen or step was confusing?

## Measure before making claims

Candidate pilot measurements include physical count versus system count, observed stockout periods, suggested versus approved quantity, actual lead time, forecast error when demand is observable, daily review time, and overrides with reasons.

The measurement set should be agreed with the pilot shop before evaluating results.
